# [C++/MFC] Shos.ClipboardSample

[English](README.md) | 日本語

**図形を複数の形式で同時に Windows のクリップボードへコピーし**、アプリケーション独自の形式から**貼り付ける**方法を示す、小さな MFC (C++) のサンプルです。

アプリケーションはシンプルな図形エディターです。ランダムな図形 (点・線・矩形・楕円) を作成し、マウスで選択し、図形全体をコピー・切り取り・貼り付けできます。

![Shos.ClipboardSample の実行画面: 描画領域にランダムな図形が表示され、Edit メニューが開いている (クリップボードに図形が無いため Paste は無効)](Images/Shos.ClipboardSample.png)

## このサンプルで示していること

| テーマ | 内容 | 主なソース |
|---|---|---|
| 複数形式でのクリップボードへのコピー | 1 回のコピー操作で、同じ図形を **拡張メタファイル**・**ビットマップ (DIB)**・**独自形式** の 3 つの形式でクリップボードに置きます。貼り付け先のアプリケーションは、自分が扱える形式を選んで使います。 | `ClipboardHelper.h` |
| 独自のクリップボード形式 | `RegisterClipboardFormat("Shos.ClipboardSample.Figures")` で登録した形式に、ドキュメントを `CArchive` でシリアライズして格納し、貼り付け時にそこから復元します。 | `ClipboardHelper.h`, `Model.h` |
| 安全なクリップボード操作 | クリップボードのオープン・クローズを RAII で行います。`SetClipboardData` に渡したハンドルは、呼び出しが失敗したときだけ解放します。貼り付け時に不正なデータがあってもクラッシュしません。 | `ClipboardHelper.h` |
| メニュー項目の有効/無効 | **Paste** は独自形式がクリップボードにあるときだけ、**Copy** と **Cut** はドキュメントに図形があるときだけ有効になります。 | `View.h` |
| Model / Document / View の分離 | `Model` が図形を保持し、変更をオブザーバーに通知します (Observer パターン)。`Document` が Model と MFC を橋渡しし、`View` が描画します。 | `Model.h`, `Observer.h`, `Document.h`, `View.h` |
| ダブルバッファリング | 描画はオフスクリーンのビットマップキャッシュに対して行い、変更された領域だけを再描画するため、ウィンドウがちらつきません。 | `DoubleBuffer.h` |
| 当たり判定 | 各図形の輪郭線までの距離を計算して、マウスカーソルに最も近い図形を見つけます。 | `Command.h`, `Geometry.h` |

## 動作要件

- Windows 10 以降
- Visual Studio 2026 と、以下のワークロード・コンポーネント
  - **C++ によるデスクトップ開発** ワークロード
  - **最新のビルド ツール用 C++ MFC** コンポーネント
- プラットフォーム ツールセット `v145`、C++20

## ビルドと実行

1. このリポジトリをクローンします。
2. Visual Studio で `Shos.ClipboardSample.sln` を開きます。
3. 構成 (`Debug` / `Release`) とプラットフォーム (`x64` / `x86`) を選びます。
4. **デバッグ > デバッグの開始** (F5) または **デバッグなしで開始** (Ctrl+F5) で、ビルドして実行します。

## 使い方

アプリケーションのメニューは英語表記です。

### 1. 図形を作成する

**Figures > Random** を選びます。位置・色・ペンの太さがランダムな図形が 10 個追加されます。繰り返すとさらに追加されます。

薄いオレンジ色の正方形が描画領域 (2000 × 2000 論理単位) です。ウィンドウの大きさに合わせて拡大・縮小して表示されます。

### 2. 図形を選択する

- 描画領域の上でマウスを動かします。マゼンタの十字カーソルがマウスに追従し、最も近い図形 (100 単位以内) が青い枠でハイライトされます。
- クリックすると、ハイライトされている図形が選択されます。選択された図形には小さな四角いハンドルが表示されます。
- 近くに図形が無い場所をクリックすると、選択が解除されます。

### 3. コピー・切り取り・貼り付け

| コマンド | ショートカット | 動作 |
|---|---|---|
| **Edit > Copy** | Ctrl+C / Ctrl+Insert | ドキュメント内の**すべての図形**をクリップボードにコピーします (拡張メタファイル・ビットマップ・独自形式)。 |
| **Edit > Cut** | Ctrl+X / Shift+Delete | すべての図形をコピーしてから、ドキュメントから削除します。 |
| **Edit > Paste** | Ctrl+V / Shift+Insert | 独自形式の図形を現在のドキュメントに追加します。既存の図形はそのまま残ります。 |

> **注意:** コピーと切り取りの対象は、選択している図形だけではなく、常にドキュメント全体です。

### 4. 他のアプリケーションに貼り付けてみる

**Edit > Copy** の後で他のアプリケーションに貼り付けると、それぞれがどのクリップボード形式を使うかを確認できます。

| 貼り付け先 | 使われる形式 | 結果 |
|---|---|---|
| Shos.ClipboardSample の別のインスタンス | 独自形式 | 編集可能な図形として追加されます。 |
| Microsoft Word / PowerPoint / Excel | 拡張メタファイル | 拡大・縮小しても鮮明なベクター画像になります。 |
| ペイントなどの画像編集ソフト | ビットマップ (DIB) | 2000 × 2000 ピクセルの画像になります。 |

### 5. 保存と読み込み

**File > Save** / **Save As...** で図形をファイルに保存し、**File > Open...** で読み込みます。ファイルには、独自のクリップボード形式と同じ `CArchive` によるシリアライズを使っています。

## クリップボード形式

| 形式 | クリップボード形式 ID | 内容 |
|---|---|---|
| 拡張メタファイル | `CF_ENHMETAFILE` | `CMetaFileDC` で作成した、描画領域全体のベクター画像。 |
| ビットマップ | `CF_DIB` | `CImage` で描画した、描画領域全体の 24 ビット画像。 |
| 独自形式 | `RegisterClipboardFormat("Shos.ClipboardSample.Figures")` | MFC の `CArchive` でシリアライズした図形データ。このサンプルが貼り付けられるのは、この形式だけです。 |

## プロジェクト構成

```
Shos.ClipboardSample/
├── Application.*        CWinApp: アプリケーションの起動 (SDI)
├── MainFrame.*          CFrameWnd: メインウィンドウ
├── Document.*           CDocument: Model と MFC の橋渡し (保存・読み込み、変更フラグ)
├── View.*               CView: 描画、マウス入力、Edit メニューのコマンド
├── Model.*              図形のリスト、変更通知 (Hint)、シリアライズ
├── Figure.*             図形クラス: 点・線・矩形・楕円
├── Command.*            マウス操作 (選択とハイライト)
├── ClipboardHelper.*    クリップボードへのコピー・貼り付け
├── DoubleBuffer.*       ダブルバッファリング対応のビュー (CView / CScrollView)
├── Geometry.h           距離の計算
├── Observer.h           Observer パターンのテンプレート
└── GdiObjectSelector.h  GDI オブジェクト選択用の RAII ヘルパー
```

### スクロールビュー版

既定では、描画領域をウィンドウに合わせて拡大・縮小して表示します。代わりにスクロールバー付きで実寸表示したい場合は、`View.h` 冒頭の `//#define SCROLL_VIEW` のコメントを外してリビルドします。

## 制限事項

- 印刷と印刷プレビューには対応していません。
- 貼り付けられるのは独自形式だけです。他のアプリケーションからの画像やメタファイルは無視されます。
- 図形は選択できますが、個別の移動・サイズ変更・削除はできません。
